# All Companies — Validated Imaging / Vision Paper List (2021–2026)

**Audit baseline:** 2026-09-03  
**Companies:** Huawei · vivo · OPPO · Xiaomi · HONOR  
**Purpose:** put the correction-aware annual research lists for all five smartphone companies into one Markdown document for cross-company comparison.

> This is an **audited research-evidence list**, not a single strict-formal-paper count. Formal papers, preprints, official projects, workshops/challenges and supporting vision/device-AI records remain explicitly distinguished. A paper is attributed to a company only when paper-time affiliation or explicit official research ownership is defensible.

## Validation rules

Before inclusion in this document, the correction-aware annual views applied the following checks:

1. exact paper identity / title;
2. formal publication vs accepted/pre-proceedings vs preprint/project/workshop/challenge;
3. paper-time company affiliation;
4. canonical formal year, or first-public year when no formal version exists;
5. arXiv/formal-version deduplication;
6. exclusion of false ownership caused only by current employment, funding, challenge organization, device usage or university collaboration.

Detailed correction log: [`PAPER_LIST_REVALIDATION_2026-09-03.md`](./PAPER_LIST_REVALIDATION_2026-09-03.md).

### Evidence shorthand

- **Huawei:** `V-S` = primary/direct verification; `V-A` = strong auxiliary evidence; `SRC` = unresolved source record.
- **vivo:** Tier A = canonical/official research-entity block; Tier B = extended affiliated research for recall.
- **OPPO:** `S` = strict/direct affiliation or official ownership; `A` = strong auxiliary; `P` = preprint/project; `C` = workshop/challenge.
- **Xiaomi:** standalone paper / preprint is separated from challenge-report contribution.
- **HONOR:** `S` = primary verified; `A` = strong auxiliary; `M` = metadata only; `P` = pending; `C` = challenge/workshop/data activity.
